## Key Features

*   **AI Bookshelf Scanner**: Scan your physical library using Gemini Vision.
*   **Smart CSV Import**: Import your library from other services with zero config.
*   **Reading Goals**: Set and track reading habits.
*   **Diversity Insights**: Analyze your library's representation.
